# Shraz Fit World

A concept shop made with Kubal for Shravan Bro, to show what his own shop could look like. It isn't a live shop, and Shravan hasn't endorsed these products.

The site is plain HTML with no build step. To put it on Cloudflare Pages, either connect this repository with no framework preset and an empty build command, or upload the files with direct upload.

- Home: `/`
- Shravan Diet: `/collections/shravan-diet`
- Munch with Shravan: `/collections/munch-with-shravan`
- Product pages: `/p/…`, one for each of the 21 products

Product names, prices and photos come from each brand's own store, as of 8 October 2026. The photos load from the brands' own image servers.
